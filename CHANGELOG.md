# Changelog

## 1.7.0 — October 22, 2026

### A clearer conversation

- Distinct Codex and Claude speaker cards, visible starting perspectives, and a simple Clarify → Discuss → Review → Answer progress indicator.
- GPT-6 Sol summarizes opening arguments, responses, and drafts into short takeaways. **Full response** reveals the original text, which the assistants still use for context and reviews.
- Paired reviews make each assistant's approval or objection to the same draft easier to compare. The final answer stays complete and distinguishes mutual agreement from a moderator decision with dissent.

### More useful context

- The moderator can ask up to three focused questions before the debate when important personal details are missing. Choose suggested answers or write your own.
- The discussion timer pauses while you answer, and pending questions survive restarting the app. **Use best judgment** explicitly allows stated assumptions for unanswered questions.
- Assistants can research unfamiliar or current public topics before assigning perspectives. Search receives the question and clarification answers, not uploaded documents or the full discussion.

### Reliability and installation

- Original responses, clarification answers, and files remain available for follow-ups and Markdown exports. Summaries do not determine agreement, and a failed summary does not discard the original response.
- Safer handling of duplicate or stale clarification answers, cancellation, remaining time, and saved state.
- Clearer installation, account connection, and upgrade instructions, with direct downloads for Apple Silicon Mac, Intel Mac, and Windows x64.

Clarification, moderation, and display summaries use the existing Codex connection and its usage allowance. No new account or API key is required. This version has no automatic updater: quit AI Collab, install the new version, then reopen it. Existing local history and settings are retained.
